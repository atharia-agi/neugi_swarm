### P1 — Perilaku yang diklaim tapi tidak dilakukan

**P1-1. `SELF_HEAL` tidak menyembuhkan apa pun tapi melaporkan sukses.**
- Bukti: `autonomous/executor.py` `_execute_self_heal` — hanya mencatat string saran dan mengembalikan sukses. Tidak ada pembersihan log, tidak ada reset circuit breaker.
- Perbaikan: implementasikan aksi nyata (panggil reset circuit breaker + rotasi/pembersihan log yang sebenarnya) ATAU ubah handler menjadi advisory yang jujur (sukses=False / status "suggestion-only") dan perbaiki klaim di AGENTS.md.

**P1-2. `OPTIMIZE` hanya mengembalikan satu saran statis.**
- Bukti: `_execute_optimize` mengembalikan saran yang sama untuk semua target; tidak ada optimasi yang diterapkan; pencatatan ke memory bergantung jalur reporter (belum diverifikasi).
- Perbaikan: implementasikan minimal satu optimasi nyata yang terukur (mis. hitung dan terapkan saran cache) atau turunkan klaim menjadi "saran optimasi".

**P1-3. Dashboard WebSocket tanpa TLS.**
- Bukti: tidak ada pemakaian SSL di `dashboard/websocket.py` maupun `server.py` (hanya CSP yang mengizinkan `ws:`/`wss:`); NEXT_STEPS tugas 7.1 masih terbuka. Mitigasi saat ini: default bind 127.0.0.1 + CORS localhost-only + auth API key otomatis saat diekspos ke jaringan.
- Perbaikan: tambahkan dukungan TLS (opsi `ssl_context`, sertifikat) untuk pemakaian di jaringan; dokumentasikan bahwa mode jaringan tanpa TLS tidak direkomendasikan.

**P1-4. `vercel.json` memakai konfigurasi legacy (`builds` + `routes` + `@vercel/static`).**
- Perbaikan: modernisasi ke konfigurasi statis Vercel saat ini (tanpa `builds`), uji deploy preview, dan hapus `routes` passthrough bila tidak diperlukan.

**P1-5. Anchor mati: `docs.html#security`.**
- Bukti: index.html menaut ke `docs.html#security`; `docs.html` tidak punya elemen `id="security"`.
- Perbaikan: tambahkan section dengan id itu di docs.html, atau ubah link ke anchor yang ada.

**P1-6. SecretManager: fallback XOR + salt PBKDF2 statis.**
- Bukti: bila paket `cryptography` tidak ada, enkripsi memakai XOR keystream + HMAC (dokumen kode sendiri menulis "Not as secure as AES-GCM"). Salt derivasi kunci adalah konstanta yang sama di semua instalasi. Mitigasi: `cryptography>=41.0` adalah dependensi wajib (requirements.txt + pyproject.toml), jadi fallback jarang terpicu pada instalasi normal.
- Perbaikan: gagalkan instalasi/operasi secara eksplisit bila `cryptography` tidak ada (jangan diam-diam fallback), dan ganti salt statis dengan salt acak per instalasi (butuh migrasi format ciphertext).
